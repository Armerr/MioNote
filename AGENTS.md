# MioNote Agent Skills

After installing the project dependencies, load the MioNote capture skill from:

`node_modules/@armerr/mionote-capture-organize/projects/mionote/mionote-capture-organize/SKILL.md`

Use it whenever the user asks to remember, classify, organize, or save a note in MioNote. The package also exposes `mionote-capture-note` for authentication, duplicate checks, and note creation. Do not put MioNote credentials in this file.
